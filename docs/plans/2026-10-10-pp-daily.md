# pp日常 Implementation Plan

**Goal:** 为单人 iPhone 使用实现可离线打卡、可备份的 PWA。

**Architecture:** Vue 3 前端以 IndexedDB 保存快照和待同步完成记录，FastAPI 同源提供静态页面与接口，SQLite 保存权威数据。仅 Tailscale Serve 提供私人 HTTPS，服务监听 127.0.0.1。

**Tech Stack:** Vue 3、TypeScript、Vite、FastAPI、SQLite、IndexedDB、Service Worker。

## 已确定规则

- Asia/Shanghai 固定日期，每项目每天只能完成一次，没有取消、补打、时长、暂停。
- 完成记录只追加，项目＋日期唯一；离线操作保存操作时刻及日期，重试幂等。
- 客户端不能指定历史日打卡；服务器校验日期等于操作时刻的上海日期，允许延迟同步。无登录、无可信设备时钟，无法阻止人为伪造客户端历史时间；这是私人单用户服务的信任边界。
- 管理在线执行：新建、改名、颜色、排序、一次性归档；归档不删除历史，不恢复。
- 月历只展示单项目；创建前、未来、归档后不适用。
- 仅累计完成、本月完成、当前连续、最长连续四项统计。今天未完成时连续计算到昨天；归档项目计算到归档当天。
- 备份恢复采用整库替换；验证完整文件并在同一事务中恢复，先自动备份；更换数据世代后旧手机队列禁止上传，提示导出本地备份后重新加载服务器数据。
- 本地导出包含未同步记录，服务器每天 SQLite backup 一致性备份，保留 30 份。

## Task 1：后端数据与核心规则

文件：backend/app.py、backend/tests/test_app.py、backend/requirements.txt。
建立项目、完成记录、数据世代；接口实现状态、在线项目管理、完成同步、JSON 导出恢复。校验操作时间、归档范围、重复记录、恢复版本和数据关联。测试重复同步、过去日期直接写入、未来时间、无取消接口、恢复事务和世代冲突。

## Task 2：四页界面

文件：frontend/src/App.vue、style.css、domain.ts、public 图标与 manifest。
手机优先，安全区域，大触摸目标；今日大日期和完成卡片，单项目月历，四指标卡片，管理表单。初始空白不预置用户项目。图标使用可缩放几何双小写 p，生成 180/192/512 PNG。

## Task 3：离线与恢复

文件：frontend/src/store.ts、frontend/public/sw.js、frontend/vite.config.ts。
一个 IndexedDB 事务写入本地完成及队列，单次同步上传队列快照，服务器成功后只清除已确认项。支持启动、回前台、online 事件和定期重试，使用 Web Locks 跨标签页串行化本地修改。缓存构建后的全部本地资源，无第三方字体或 CDN；网络 API 不进入 Service Worker 缓存。

## Task 4：验证与交付

文件：README.md、scripts/backup.py、scripts/install-macos.sh、scripts/dev.ps1、frontend/src/domain.test.ts。
运行 pytest、前端统计规则测试、vue-tsc 和生产构建；浏览器验证新建、完成、不可重复、月历、统计、归档及备份。Mac 安装脚本创建 launchd 服务和每日备份任务；文档写明 Tailscale HTTPS、更新、备份目录、iPhone 添加主屏幕和真机验收清单。

## 验收命令

```
python -m pytest backend/tests -q
cd frontend
npm ci
npm test
npm run build
```

Mac 和 iPhone 不在当前执行环境中，自动启动、Tailscale ACL、Safari 主屏幕/离线持久化需部署后真机验收。
