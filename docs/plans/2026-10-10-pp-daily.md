# pp Daily 开发计划与实现状态

本文件按 2026-10-10 的最终实现更新；本地自动化验证已完成，iPhone 15 与 Mac mini 真机验收待执行。

**Goal:** 为单人 iPhone 15 使用实现可离线打卡、可备份的 PWA，Windows 开发、Mac mini 部署。

**Architecture:** Vue 3 前端以 IndexedDB 保存快照和待同步完成记录，FastAPI 同源提供静态页面与接口，SQLite 保存权威数据。仅 Tailscale Serve 提供私人 HTTPS，服务监听 127.0.0.1。

**Tech Stack:** Vue 3、TypeScript、Vite、FastAPI、SQLite、IndexedDB、Service Worker。

## 已确定规则

- Asia/Shanghai 固定日期，每项目每天只能完成一次，没有取消、补打、时长、暂停。
- 完成记录只追加，项目＋日期唯一；离线操作保存操作时刻及日期，重试幂等。
- 客户端不能指定历史日打卡；服务器校验日期等于操作时刻的上海日期，允许延迟同步。无登录、无可信设备时钟，无法阻止人为伪造客户端历史时间；这是私人单用户服务的信任边界。
- 管理在线执行：新建、改名、单字图标、颜色、排序、一次性归档；归档不删除历史，不恢复。
- 月历只展示单项目；创建前、未来、归档后不适用。
- 仅累计完成、本月完成、当前连续、最长连续四项统计。今天未完成时连续计算到昨天；归档项目计算到归档当天。
- 备份恢复采用整库替换；验证完整文件并在同一事务中恢复，先自动备份；更换数据世代后旧手机队列禁止上传，提示导出本地备份后重新加载服务器数据。
- 本地导出包含未同步记录，服务器每天 SQLite backup 一致性备份，保留 30 份。

## Task 2：四页界面

文件：frontend/src/App.vue、SwipeComplete.vue、ProjectPicker.vue、swipe.ts、style.css、domain.ts、public 图标与 manifest。

- 使用米白与墨绿、小写衬线字标 `pp daily`、SVG 导航，适配 iPhone 15 的页面宽度和安全区域。
- 今日页顶部显示小字号年月与最近七天日期栏；历史日期只读，仅展示当时存在的项目。
- 未完成项目每项一行，整行向右滑动约 120 CSS 像素后松手完成。点击、短滑、左滑和纵向手势不触发完成，短滑复位；键盘可调整进度后确认。
- 完成项目移到下方独立、可折叠的「已完成」栏，左侧仅显示对勾。未完成项目显示自定义单字图标，留空则使用项目名称首字；每行显示以今天为基准的当前连续天数。
- 月历仅展示单项目，统计仅展示四项指标；两页共用米白项目选择面板，手机从底部弹出，桌面居中显示，当前项目有选中标记。
- 管理页支持创建和编辑项目名称、图标文字与颜色，以及排序、归档和备份恢复。移除冗余页面标题、今日完成汇总、常驻滑动提示与选择项目文字标签。
- 初始数据为空，不预置用户项目。主屏幕图标使用墨绿底的双小写 p，提供 180/192/512 PNG；主屏幕默认名称为 `pp Daily`。

## Task 3：离线与恢复

文件：frontend/src/store.ts、frontend/public/sw.js、frontend/vite.config.ts。
一个 IndexedDB 事务写入本地完成及队列，单次同步上传队列快照，服务器成功后只清除已确认项。支持启动、回前台、online 事件和定期重试，使用 Web Locks 跨标签页串行化本地修改。缓存构建后的全部本地资源，无第三方字体或 CDN；网络 API 不进入 Service Worker 缓存。
